# Chessmaster

A responsive chess landing page and interactive practice board, built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required.

## What's included

- Responsive Chessmaster home screen with play, puzzles, learning, and community sections.
- Interactive chessboard with piece selection, basic movement, turn alternation, captures, pawn promotion to queen, flip, undo, and reset controls.
- Quick-match and account buttons with clear coming-soon feedback.

The practice board demonstrates basic piece movement and does not currently enforce check, checkmate, castling, or en passant. Online matchmaking, accounts, lessons, and puzzles are not implemented yet.
